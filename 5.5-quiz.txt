Question #1
For each statement, identify:

    Whether the initializer is a constant expression or non-constant expression.
    Whether the variable is a constant expression or non-constant expression.

a)
char a { 'q' };

Answer: initializer => constant expression, variable => non-constant expression


b)
const int b { 0 };

Answer: initializer => constant expression, variable => constant expression

c)
const double c { 5.0 };

Answer: initializer => constant expression, variable => non-constant expression (non integral type)


d)
const int d { a * 2 }; // a defined as char a { 'q' };

Answer: initializer => non-constant expression, variable => non-constant expression (initializer isn't constant expression)


e)
int e { c + 1.0 }; // c defined as const double c { 5.0 };

Answer: initializer => non-constant expression, variable => non-constant expression


f)
const int f { d * 2 }; // d defined as const int d { 0 };

Answer: initializer => constant expression, variable => constant expression

g)

const int g { getNumber() }; // getNumber returns an int by value

Answer: initializer => non-constant expression (function returns variable value), variable => non-constant expression

h)
Extra credit:

const int h{};

Answer: initializer => constant expression, variable => constant expression
